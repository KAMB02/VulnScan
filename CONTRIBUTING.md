# Contributing to VulnScan

Thank you for your interest in contributing to **VulnScan**!  
VulnScan is an open-source command-line tool for vulnerability scanning and analysis, built in PHP for Linux systems. It automates security scans using Nmap and NSE scripts, then interprets results to provide clear, detailed, and actionable reports.

We welcome contributions from the community. Please follow the guidelines below to ensure smooth collaboration.

---

## 🐛 Reporting Issues
- Use the **Issues** tab to report bugs or request features.
- Provide a clear description:
  - Steps to reproduce the problem
  - Expected vs. actual behavior
  - Logs, screenshots, or error messages if available

---

## ✨ Suggesting Enhancements
- Open an issue describing your idea.
- Explain the use case and potential benefits.
- Be specific about how it improves VulnScan.

---

## 🔀 Pull Requests
- Create a new branch for your work:
  - `feature/<name>` for new features
  - `fix/<name>` for bug fixes
- Ensure your code runs correctly before submitting.
- Add tests when possible.
- Write clear commit messages and PR descriptions.
- All changes must go through a **Pull Request** for review.

---

## 📐 Code Style
- Follow **PSR-12** PHP coding standards.
- Comment complex logic for clarity.
- Keep commits small and focused.
- Use meaningful variable and function names.

---

## 🔒 Security Guidelines
- Do not add code that could compromise security.
- Test changes only in authorized environments.
- Report any security concerns privately before opening a public issue.

---

## ✅ Testing
- Run existing tests before submitting a PR.
- Add new tests for new features or bug fixes.
- Ensure compatibility with Linux systems.

---

## 📄 Licensing
By contributing, you agree that your code will be licensed under the same license as VulnScan.

---

Thank you for helping improve VulnScan!

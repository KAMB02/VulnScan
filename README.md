# VulnScan
VulnScan est un outil open source de scan et d'analyse de vulnérabilités en ligne de commande, développé en PHP pour les systèmes Linux. Il automatise les analyses de sécurité à l'aide de Nmap et de ses scripts NSE, puis interprète les résultats afin de fournir des rapports clairs, détaillés et exploitables.
